# Web Firmware Updater
You'll find any relevant documentation on the Web Firmware Updater [website](https://intellijel.github.io/firmware/) itself!

A [compatible](https://caniuse.com/webusb) web browser required.

## Older firmware 
You _may_ find older firmware in this repository, but be warned that your settings and/or presets may not transfer properly if you downgrade from newer firmware version.

**_Downgrade at your own risk, any stored data may become unrecoverable. Your module will still function, but may require you to reset to the factory settings._**

Only the latest versions (and newer beta versions) are displayed on the Updater website.
