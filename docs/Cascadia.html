Cascadia

Entering Bootloader

  1. Turn off power to Cascadia.
  2. Remove any speakers or headphones to avoid unwanted sounds, or loud noises.
  3. Connect a USB cable from the rear of Cascadia to your computer.
  4. From the version menu above, select the firmware version you will be updating to.
  5. Hold down the MIDI PITCH button on the panel and turn on power.

1.3.0.0 (2023-12-19)

  • NEW: Dual Mono MIDI Mode — Add a 2nd MIDI Pitch and Gate.
    • Hold down MIDI CC button on boot to Toggle ON/OFF (or use IntellijelConfig.App 1.5+)
    • Tap the MIDI CC button to learn the MIDI channel for the 2nd voice.
    • CC = Pitch 2
    • MOD = Gate 2
    • Additional coarse tuning/pitchbend options available in the IntellijelConfig.App.
  • NEW: Option Env B LFO Mode called the ESG (Entropic Sequence Generator).
    • Hold down MIDI LFO button on boot to Toggle ON/OFF (or use IntellijelConfig.App 1.5+)
    • It will replace the Tilt Triangle LFO on Env B. See the Manual for details.
    • RISE = Rate.
    • FALL = Sequence length (1 to 16 stages).
    • SHAPE = Step regeneration probability (0% to 100%).
    • In LFO-SYNC Mode, the SYNC input will set the base rate.
    • In LFO-FREE Mode, the SYNC input will Reset the Sequencer.
  • Updated manual and Config App (1.5.0.0 or higher required) available at intellijel.com/support.

1.2.0.2 (2023-05-08)

  • NEW: New MIDI LFO shape: "Random Notes" added to the list of LFO shapes available at the MIDI LFO output. Random Notes outputs clocked random voltages, which are quantized to semitones. You can constrain the octave distribution by using the new LFO Level and LFO Polarity options in the Intellijel Config app's MIDI LFO section (see below).
  • NEW: LFO Level parameter in the Intellijel Config App's MIDI LFO section. This sets the maximum output voltage (amplitude) of the MIDI LFO to either 1V, 2V, 3V, 4V or 5V (the default). NOTE: This parameter is only available via the Intellijel Config app, and can not be set on the front panel.
  • NEW: LFO Polarity parameter in the Intellijel Config App's MIDI LFO section. This selects whether the MIDI LFO is Unipolar or Bipolar (the default). When set to Bipolar mode, the LFO output ranges between the negative and positive voltage set by the LFO Level parameter. NOTE: This parameter is only available via the Intellijel Config app, and can not be set on the front panel.
  • NEW: Support for MIDI Portamento mode. Specifically, CC 65 (Portamento Control) on Cascadia's MIDI Channel turns portamento ON (value = 127) or OFF (value = 0). Sending CC 5 (Portamento Time MSB) on Cascadia's MIDI Channel sets the portamento time from 0 seconds (CC 5 = 0) to about 1.1 seconds (CC 5 = 127), slewing the pitch.
  • Minor bug fixes and performance enhancements.
  • Updated manual and Config App (1.4.1.0 or higher required) available at intellijel.com/support.
