Tetrapad

Entering Bootloader

  1. Turn off power to your modular system.
  2. Connect a USB cable from the rear of the module to your computer.
  3. Hold down the white button on the front of the module and turn on power to your modular system.

Changelog

3.1.1.0 (2026-05-05)

Note: These fixes only affect standalone Tetrapad operation. No difference will be noticed when connected to a Tête.
  • Fixed Latch/Slew Settings not saving in Combo Mode.

3.1.0.2 (2021-07-12)

Note: These fixes only affect standalone Tetrapad operation. No difference will be noticed when connected to a Tête.
  • Fixed polarity selection for Combo Mode LFO pads.
  • Fixed incorrect LFO speed in Combo Mode on boot or switching pad types.

3.1.0.1 (2021-07-12)

Note: Recommended update for both standalone and Tête users.
  • Increased LED frame rate to ensure really short gates are reflected on the LED.

3.1.0.0 (2021-07-02)

Note: Recommended update for both standalone and Tête users.
  • Clock/Gate LEDs are now Amber colour (and dimmer) to match our lineup going forward.
  • Fix for -5V settings outputting uncalibrated voltage.
  • Perform a Factory Reset when holding ENC 1+4 on boot.

3.0.0.3 (2020-03-27)

Note: These fixes only affect standalone Tetrapad operation. No difference will be noticed when connected to a Tête.
  • BUGFIX: Latched bi-polar pads Combo Mode loading at -5V.

3.0.0.2 (2020-03-26)

Note: These fixes only affect standalone Tetrapad operation. No difference will be noticed when connected to a Tête.
  • FEATURE: Encoder LEDs light up green when you save a preset.
  • FEATURE: Doubled the slowest slew time in Combo Mode.
  • BUGFIX: Combo Mode presets not loading some parameters.
  • BUGFIX: Encoder response glitches introduced in 3.0.0.1.

3.0.0.1 (2020-03-02)

  • CHANGE: Coarse/Fine tuning now handled with Encoder Acceleration. Turn slowly to increment in slowly, and turn faster to increment more quickly. (No need to Push-Turn the encoder for fine increments)

3.0 (2019-11-13)

  • FEATURE: Support for Tête! When connected to the Tête please refer to the Tête manual as Tetrapad functionality differs.
  • FEATURE: Better Rainbow in Settings mode. :)
  • FEATURE: Tuning Mode to Added to Keyboard and Chord Modes, SHIFT-CONFIG (RED+WHITE) to Toggle. Outputs C0 (0V) on all pitch outputs, and high gates on the TRIG/GATE outputs
  • BUGFIX: Easier to touch the extreme ends of the pads/voltage range.

2.0 (2018-10-30)

  • FEATURE: Faders, LFO, drum, and switches modes have been consolidated to one "combo" mode which is the default mode 1. Other modes have been shifted around. Push the white button to set the function of each fader in combo mode, hold the white button to switch to a different mode.
  • FEATURE: Presets, 12 slots for each mode.

1.10 (2018-6-15)

  • FEATURE: Voltage mode slew rates dependant on pressure.
  • FEATURE: Increased maximum slew times.
  • BUGFIX: Fixed lydian scale notes.
  • BUGFIX: Fixed voltage range for voltages mode.

1.00 (2017-9-31)

  • Initial release.
