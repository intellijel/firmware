Metropolix

Entering Bootloader (Metropolix Solo / Setup Menu)

  1. When powered on, click the SETUP button, scroll down to "Update Firmware" and follow the Prompt.
  2. Note: you may need to disconnect and reconnect the USB cable for the module to be recognized again after an update.

Entering Bootloader (Alternate)

  1. Turn off power to your modular system.
  2. Connect a USB cable from the rear of the module to your computer.
  3. Hold down the BOOT button on the rear of the module and turn on power to your modular system.

1.6.2.2 (2026-08-17)

WARNING: BETA RELEASE — BACK IT UP! You can backup your presets over SysEx as explained in the manual!

  • New: Mx and A/B Output options— Setup programmable or derivative Trigger/Gate Sequencers from Mod Lanes!
    • A/B Outputs > Mod Trig — Derives Trigs from a selected Mod Lane.
    • Mx Outputs > Mod Gate and Mod Trig — Derives gates and trigs from all 8 Mod Lanes for output on the Gx/Qx or via MIDI CC/Note.
    • Setup > MIDI Mx Ch — Duplicated for easy access from Mx page.
    • Setup > MIDI Mx Output: CC or Note — You can now output MIDI Note messages derived from the Mx outputs; use these to Trigger midi devices.
  • Beta notes (will be in manual)—
    • You can combine these new options with a Mod Lane's CV Type="Gate Toggle" to enter patterns like a step sequencer, or just see what patterns emerge from existing Lane values or Mx options. Velocity will be 127 in this case.
    • Mod Gate and Mod Trig Note Velocity and CC Value will be derived from the Lane's Stage value.
    • Triggers are 5ms long, and gates will tie at the initial value until a stage goes low.
    • MIDI Notes are fixed, Mx Outputs 1-8 (top to bottom) will output MIDI Notes 35-42.
  • Tweak: Mx Stage Num options, now only output when the sequencer is running.

1.6.0.0 (2025-09-24)

  • New: Set the Root Note with a MIDI Note On Message.
    • New Global Setting for setting the "MIDI Root Ch."
    • Changes the Root Note Setting to the last received Note on the specified MIDI Root Channel.
    • Since we are changing the setting, the latest changes will be saved to state and when you save a preset.
    • Does not affect Custom Scales, since they are configured with their own specific root note.
  • New: Load Presets with MIDI Program Change messages.
    • New Global Setting: MIDI PC (Program Change) Ch.
    • MIDI program change messages 0-63* will select Metropolix presets 1-1 to 8-8 (bank-slot) on the configured channel.
      *Note: Your software or device may display the program numbers as 1-64.
    • Presets will be loaded according to the Load/PC Delay option on the Preset Load screen.
    • Program Changes will be ignored if a Preset Chain is running, or the Preset does not exist yet.
  • New: Immediate RESET/RUN behaviour.
    • RUN and RESET now happen immediately when the button is pushed. The old Click/Hold-Release behaviour has been removed.
    • Internal clock: RUN will start immediately, resetting the phase of the internal clock.
    • Internal clock: ALT+RESET will Reset immediately, also resetting the phase of the internal clock.
  • New: "Reset Input" mode, "Run-C" or Run-Continue. Which does not Reset the sequence when the input signal goes low. You can use the RESET button for a manual reset.
  • Tweak: When Root is assigned to a CTRL knob, the range is ±12 Semitones instead of ±11, allowing you to reach the next octave.
  • Tweak: When Root modulated via AUX or MOD Lane upwards beyond +1 octave (>=1V), the root note will wrap at 1 octave higher, similarly when you modulated downwards beyond -1 octave (<=1V), the root will wrap around at an octave lower.
  • Tweak: No "Pitch Pop-up" when you are on the "Pitch" Home view, allowing you to dial in and see all the stage pitches as you adjust them.
  • Tweak: Increased encoder acceleration for most edit pages. Parameters and Menus with a small range are not accelerated.
  • Fixed: Root/Scale display was incorrect if Root was adjusted but not confirmed.
  • Fixed: Modulation on Root Note is reflected correctly on A/B outputs, as well as the "Bottom Pitch" setting when set to "Root".
  • Fixed: Late modulation on some position related parameters. (Stages Len, Stages Offset, Loopy Offset)
  • Fixed: UNDO functions were not working on the Mod Lanes and Track CV pages.
  • Fixed: Decreased the brightness of the "DIM" state of LEDs for more contrast (most noticeable on Presets Page).

1.5.1.0 (2024-05-16)

  • NEW: Support for the Metropolix Solo w/ TRS MIDI Jacks via i2C port.
    • Enabled by default. All MIDI settings also work with USB.
    • TRS MIDI support is disabled when a Gx or Qx are connected.
  • NEW: Mx Expander settings can now be output as MIDI CC.
    • By default Gx MIDI Channel is Off.
    • Gate Outputs 1-8 corresponds to CC 102-109 on the Channel selected on the Mx Setup screen.
    • Mx Screen has a new param for setting MIDI Channel (set with ALT).
  • NEW: Updated Default Track Options:
    • Velocity: 100%
    • Track MIDI Channels:
    • Track 1: MIDI CH 1
    • Track 2: MIDI CH 2
    • Track CCs:
    • CV to CC: CC #1
    • Slide* Toggle CC #65
    • Slide* Amount CC #5
    • (*NOTE: Slide config matches Cascadia defaults)
  • NEW: MOD Lane MIDI Defaults:
    • MIDI Channel for all MOD Lanes: CH 1
    • MOD Lanes 1-8 CC Values: 20-27
    • Track 1: MIDI CH 1
    • Track 2: MIDI CH 2
    • Track CCs:
    • CV to CC: CC #1
    • Slide* Toggle CC #65
    • Slide* Amount CC #5
    • (*NOTE: Slide config matches Cascadia defaults)
  • NEW: Unipolar/Bipolar CV options on the CV TYPE screen for setting CV display to either Unipolar, Bipolar, or Gate Toggle. The CV Type is set per-Lane, so it can be set individually for each MOD Lane and for the CV Lane in a Track. To access it:
    • Press ALT+CV (Stage 8) to display the CV TYPE screen.
    • Note: If a MOD Lane is assigned to an internal parameter, then the MOD Lane type will follow that selection, either: Bipolar or Gate.
    • Note: If Track CV is also assigned to Track Velocity, then the CV Type will be forced to Unipolar (for Setting Velocity directly), or GATE (for Setting Accent toggle style).
  • NEW: CC value display on the Stage Edit screen for Track CV and Mod Lanes:
    • Values are still entered as Voltages (or in the case of Mod Lane, based on the parameter ranges). But you can see the CC value that will be sent if you also have the lane assigned to CC.
  • NEW: SCALES can now be copied & pasted to user (custom) scale slots.
    • Copy: Press ALT+SCALE on ANY scale.
    • Paste: Long Press (1 sec) ALT+SCALE on ANY CUSTOM scale slot.
  • NEW: Option for setting a default preset to use when selecting Init Preset on the SETUP screen. This is done via the new Set Init Preset option, which is beneath the Presets Setup options also on the SETUP screen. Specifically:
    • On the SETUP screen, scroll down to Presets Setup and click the encoder to select it.
    • Scroll down to the new Set Init Preset option and click the encoder to select it.
    • Use the encoder to select between “—” (off) or a Preset number “1”-”64” (aligned with the 8 banks of 8 presets). The selected preset will then be used as the default starting point when you initialize a new preset. It loads everything saved with a preset (including Aux/Ctrl Assignments), but does not load Pitch slider, or Switch positions.
  • NEW: “Quasi Random” play ORDER, which is similar to the “Random” order, except that the same stage will not play twice in a row if the LENGTH contains more than two stages. Because every stage is quasi-randomly selected, sequences do not cycle and do not automatically reset.
  • NEW: CV Output Delay (in the UI Setup menu) — dial in up to 21ms of CV Output delay (all CV/Gate Outputs including MX). This helps to sync Modular voices with DAW output. This setting does not affect MIDI output.
  • CHANGE: Changing the Transpose value in the Track Menu now requires you to confirm the value before it takes effect.
  • CHANGE: Changing Root Note on the SCALE Screen now requires you to confirm the value before it takes effect. (Exception: When editing a Scale, the root note will update as you change it.)
  • CHANGE: Bottom Pitch on a PITCH SLIDER can now be assigned to any note. Previously the Bottom Pitch parameter, on the SETUP screen, allowed you to select whether the bottom note on a PITCH SLIDER was assigned to the scale's root note or to a “C.” Now you can select any note (not just “C”) to assign to the bottom note on the PITCH slider. As before, if the current scale does not include the chosen note, then the bottom pitch will be the first in-scale pitch above it.
  • CHANGE: DIV Factory Shortcuts updated to a more useful default of: /1, /2, /3, /4, /6, /8, /16, /32
  • FIXED: Pitch Dialog now updates when changing scale or root if no gate has been sent.
  • FIXED: MIDI Clock outputting when Clock: Running setting is ON. It will now only output if Metropolix is running.
  • FIXED: Track Swap Support on MIDI, When Swap is enabled, only the MIDI Channels are swapped.
  • FIXED/TWEAKED: Other minor UI bug fixes/tweaks.
