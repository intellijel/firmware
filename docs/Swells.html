Swells

Entering Bootloader

  1. Turn off power to your modular system.
  2. Connect a USB cable from the rear of the module to your computer.
  3. Hold down the BOOT button on the rear of the module and turn on power to your modular system. Note: The LEDs will not light up when in bootloader mode.

Changelog

1.3.0.0 (2026-11-19)

  • New: Compressor or Tape Lo-Fi modes can be enabled on any of the 9 models!
    You can override the default Lo-Fi types on each Model by holding ALT and simultaneously moving the position of the LO-FI switch.
    • (OFF) Default per-bank Lo-Fi effects
    • (MIN) Lo-Fi Tape effect on all banks
    • (MAX) Lo-Fi Compressor effect on all banks
    • Note: When in Bank Z, and in Lo-Fi Override mode, you can hold ALT+BURST while adjusting the LO-FI switch to change the underlying Model's Lo-Fi setting. This is saved per-Model when Lo-Fi override is enabled.
  • New: INPUT (Knob)/DRIVE position (like Sealegs)
    This changes the signal chain position of the INPUT knob and it's function, matching a similar option in Sealegs. Note that Swells has a DRIVE toggle, which is a bit different than Sealegs. Toggle by holding ALT and changing the (IN/SC/OUT) Switch, the middle position is the factory default.
    • When DRIVE is disabled—
      • (IN) Input level (affects dry and wet)
      • (SC) Verb input (default)
      • (OUT) Clean post-mix boost into compressor
    • When DRIVE is enabled (matching Sealegs)—
      • (IN) Input drive (affects dry and wet)
      • (SC) Verb input drive (default)
      • (OUT) Post-mix drive into output compressor
  • Note: These new ALT+Switch functions require you to hold ALT while the switch changes position, unlike the other panel-labeled Alt functions.
  • Tweak: TRIG inputs will invert (instead of OR) the associated button state.
  • Fixed: Cleaner noise floor.
  • Fixed: CV Calibration not being applied correctly (regression).
  • Updated manual with full UI details available at intellijel.com/support.
