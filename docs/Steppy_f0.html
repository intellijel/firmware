Steppy 1U (rev001/rev002) and 3U (rev001)

Entering Bootloader

  1. Turn off power to your modular system.
  2. Connect a USB cable from the rear of the module to your computer.
  3. Hold down the EDIT (Red) button and turn on power to your modular system.

1U / 3U Toggle

Steppy’s 1U and 3U versions run the same firmware, which supports both button orientations. The correct orientation is loaded at the factory, and any subsequent firmware updates should retain the correct orientation. However, if you one day find your Steppy operating as if all the button functions are inverted, it means the opposite orientation is running.

To toggle between the 1U and 3U orientation, simply hold the SELECT button at startup, and the orientation will toggle.

  • FIXED: Hanging after upgrade to 1.2.0

1.2.0 (2020-01-16)

  • NEW: Latching Loopy mode. When Holding down Loopy steps, tap the SEL button to Latch your loop. Press a step button to release. If you change your Loopy steps, you will need to press SEL to latch them again.
  • NEW: Delayed load. When on the LOAD page, you can long-press a preset to have it load when the current pattern reaches its last step on track 1.
  • NEW: Muted tap entry mode. When in TAP Recording Mode, you can press the "PROB" button to toggle muting your taps. The ABCD buttons will turn Yellow to indicate Muted.
  • NEW: Step Edit mode (per-step gate length, delay, probability (and still Ratchets). This changes the UI for editing ratchets, as you can now edit 3 other parameters. Details will be found the updated manual.
  • FIXED: Track Probability is now applied to the current position, and will not randomize individual ratchets.

1.11 (2019-10-10)

  • Additional filtering on Clock input to handle imprecise clock pulses.

1.10 (2019-08-14)

  • Added toggle for RESET Mode and New RUN Mode — Hold RST (Save) on boot.
  • On the SEL page, you'll see the RST LED Lit solid Yellow if RUN mode is enabled.
