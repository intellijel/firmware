Multigrain

Entering Bootloader

  1. Turn off power to your modular system.
  2. Connect a USB cable from the rear of the module to your computer.
  3. Hold down the BOOT button on the rear of the module and turn on power to your modular system.

1.3.9.2 (1.4 Beta) (2026-01-12)

WARNING: BETA RELEASE — BACK IT UP! Backup the whole /Multigrain folder from the SD card before booting the new firmware!

  • New: 2 New Per-Sound Options — Enable any combination of these.
    Note: the Blur effect is not choked or gated and will decay as expected.
    1. Choke Sound
      Choke Sounds will cut off any existing grains when they are triggered.
    2. Gate Sound
      Gate Sounds will instantly end any existing grains when the "gate" goes low; the "gate" can be the GATE input, holding the SOUND button down, or latching the sound.
  • New: Alt Page UI for Per-Sound Options: Live, Choke, Gate
    Note: The existing Home Page Toggle for Live Sounds (SOUND+SAMPLE) is still active.
    1. Enter the ALT page and hold the SOUND button down to view or tweak that Sound.
    2. The 4 LED Buttons in the Grain Section will change function while the SOUND is held to show and toggle the Sound Options.
      • SAMPLE will toggle LIVE (Toggle Live Sound)
      • LINK/LOAD will toggle CHOKE (This still stop any audio before this Sound is fired)
      • LINK/SAVE will toggle GATE (This will stop any audio when the GATE on this sound is released)
      • REVERSE is currently disabled in this context
    • You can hold LATCH along with any SOUND to set these options for ALL Sounds
    • New Choke and Gate Sound options can be saved with the default Sound or default Live Sound.
    • These options are saved in your preset.
  • Tweak: Previous Beta/Global Sound Choke toggles removed from System Page Options.
  • Tweak: Increased max gain for Input Gain from 2.5x (~8dB) to 8.5x (~18.5dB) — The Input Gain setting will reset to 1x (Noon) when you load this update.
    Note: that this is digital gain and will boost your noise floor. Analog gain is always recommended to boost quiet sources into digital modules.

1.3.9.0 (1.4 Holiday beta) (2025-12-24)

WARNING: BETA RELEASE — BACK IT UP! Backup the whole /Multigrain folder from the SD card before booting the new firmware!

  • New: System Page Options
    1. Gate Delay
      This will delay the GATE signal to allow slower CV sources to catch up before a Sound is triggered. Use START on the System Page to add up to 8ms to the internal Gate Delay, full CCW is the minimum. (For example, the Arturia Keystep may require a higher delay for PITCH CV to respond in time with the GATE).
    2. Sound Chokes
      Choked Sounds will cut off any existing grains when they are triggered—Mix Choked and Non-choked Sounds. Use the SOUND buttons on the System Page to enabling Choking for a specifc SOUND button. Try Choking your sample Sounds but leaving your Live Sounds to decay gracefully.
  • New: New MOD A/B Output Options
    1. Threshold Gate (YELLOW)
      Follows the Record Threshold option, sends a gate when the input signal has passed the threshold; if threshold is disabled it uses the minimum value, this can be sensitive based on what is patched, just increase threshold if too sensitive. Try self-patching to GATE to have it sounds play only when audio is received by multigrain! Taking this further, you can also use it with the NEXT=RESET System option to re-align the playheads (to START) when new audio is captured.
    2. Record Trig (PINK)
      • If Sampler: Sends a TRIG when Recording Starts, great for triggering modules and recording a 1 shot.
      • If Looping Recorder (when using Live Sounds): Sends a GATE when the recorder is recording, and goes low when it's frozen or waiting for audio.
  • Fixed: If RESAMP was enabled, and there was no Live Sounds, it would not activate properly on boot.
  • Fixed: Theme Changes were not being saved. (Allow 10sec or so after boot for the change to save to SD).

1.3.0.0 (2025-10-02)

  • New: Collect and Save Presets and Projects — 3 Ways
    Collect any .wav files in the /Wavs and /Recs folders that are referenced in presets into the preset's /ProjectXX folder. Just like the "Collect and Save" on Bitwig or Ableton. If a matching filename exists in the project, it will be compared to the new one, and if it's the same file, the reference will be updated to the file already in the project without copying, otherwise a -1 (or -2, -3...) will be appended to the filename when it's copied (example Rec0420-1.wav).
    1. Auto-Collect on Preset Save
      • Enabled from the System Page, see notes below.
      • When ON, any "external" sound references in the current state will be copied to the current project folder and the Sound references will be updated when a Preset is saved (even Quick save).
      • If all the sounds are already in the project, this action does not add any time to the save routines.
    2. Manual Collect and Save a Project
      • Manually collect all the files for ALL the Preset and Autosave files inside a Project.
      • From the Projects Page, hold one of the 8 project buttons for 4 Seconds, it will flash quickly as it collects everything in that project, the SD LED should blink rapidly.
      • The Projects you've collected while on the Project Page will turn Green (this display will reset when you leave the Projects Page.
      • Collecting a project WILL collect and update "Locked Presets".
    3. Manual Collect and Save for ALL Projects at once
      • Hold /PROJECT (X) on boot, until the bottom LEDs light up in blue, this will collect and save every preset in every project.
      • When it's complete, it will boot normally
      • This should allow you to delete/reset the contents of your /Recs or /Wavs folder, without fear of breaking any Presets/Projects.
  • New: System Page Settings — Something for everyone
    Note: these are system wide settings, and could affect how your presets sound when they are loaded. You can enter the System Page by holding ALT+REVERSE for 4sec.
    • Auto-Collect on Preset Save (Noted above)
      • Press /PROJECT (aka X) to toggle "Auto-Collect on Preset Save"
      • YELLOW: Auto-Collect Enabled
      • DIM: Auto-Collect Disabled (Default)
    • Extended Grain Lengths (Experiment with longer Max Grain Sizes. 4 settings are available)
      • Selected with SIZE knob
      • GREEN: 4 Sec (Default in 1.2)
      • PURPLE: Smaller of 4 Sec or Sample Size* (New Default)
      • RED: Smaller of 8 Sec or Sample Size*
      • BLUE: Full Sample Length (Experimental, it really destroys the resolution of the SIZE control, but can be fun for ambient)
      • *Prevents looping short samples in a longer grain
    • Toggle the 30sec Idle Timeout return to Home Page
      • Press CLEAR to Toggle the "Idle Timeout" option that returns you to the home page after 30 sec.
      • YELLOW: Timeout Enabled (Default)
      • DIM: Timeout Disabled
    • Toggle Pass-thru (aka Catch) Knob Behaviour
      • Press THRU to enable Pass-thru (aka Catch) Knob Behaviour
      • YELLOW: Pass-thru
      • DIM: Jump (Default)
    • Pitch Mod A/B Output Scale
      Note: This does not affect and is not needed for internal V/Oct tracking on the X/Y/Z inputs when assigned to PITCH. If you notice that your Oscillator/Voice does not track with the Multigrain Pitch Mod output option, you can adjust the scaling here; alternatively, try patching the MOD output thru a buffered mult before your oscillator v/oct input.
      • Use the PITCH knobs Adjust the Scaling from [1.0x to 1.1x] for the Pitch Mod out option. (Default is 1.0)
      • On the System Page, the MOD A and B output will output scaled voltages.
      • Use the SIZE-PITCH Link button to toggle between [0, 1, 2] Octaves on the MOD outputs, use these to calibrate your oscillator/voice.
  • New: Set Default State for Sounds and Live Sounds separately
    • Configure a Sound or Live Sound with the default panel settings, quantizer, and mod assignments.
    • Hold that SOUND button, then hold SAVE for 1 sec, the SAVE LED will flash for a couple sec. The defaults will be saved for the type of sound held.
    • To Reset to Factory Defaults: Hold any SOUND button (Sound or Live Sound) and hold LOAD for 1 sec, the SAVE LED will flash for a couple sec. The default state for the type of sound held will be reset to factory.
  • Tweak: No SD Card — All Sounds will default to Live.
  • Tweak: Sample Settings — Show RED LED when LEVEL is at unity.
  • Tweak: Env Followers — Increased input gain, shortened att/rel by 50%.
  • Tweak: When switching from Resampling recorder to the Looping recorder, the buffer will be cleared.
  • Tweak: Grain Handling with 3 new Extended Grain Size Options — Allows more long grains to overlap.

1.2.0.0 (2025-07-03)

  • New: Live Sounds — Generate Grains from Live Input!
    • Any and all Sounds can be a Live Sound, generating grains from the New Looping Recorder.
    • Mix Live Processing with Sample Sounds across the 8 Sounds buttons.
    • Use multiple Live Sounds to sequence between different Effect Parameters.
    • Hold a SOUND button and press SAMPLE to Toggle! The SOUND button will turn MAGENTA, when enabled and PINK when GATE/LATCHED. The Looping Recorder will be enabled automatically.
    • Enable SYNC to quantize the START-SCAN-WRAP position to a multiple of your incoming SYNC time.
    • If you save the Looping Recorder to an Empty Sound, it will copy the settings from the current Live Sound.
    • Multigrain offers more control than a typical granular effect and we didn't want to limit any control with the introduction of Live Sounds. Built-in Click reduction will avoid any sharp clicks if your grains cross over the record head, so go wild with modulation and let Multigrain handle it! You can of course tune your parameters to completely avoid any Grain/record head collisions.
  • New: Looping Recorder — With CV over Freeze/Listen.
    • Auto-enabled for Live Sounds, but also great for sampling drones.
    • Toggle between Frozen (CYAN) and Listening (MAGENTA) using the SAMPLE button.
    • Assign RAND/X/Y/Z to Freeze/Listening Toggle (a Global/Preset Level assignment).
    • Supports threshold Based Auto-Freeze (follows your THRSH Setting).
    • Auto Crossfade over loop point when freezing (100ms) for smoother Loops/Freezes.
    • Save your Loops to the SD Card (Long Press SAMPLE) like you would any other sample.
    • Samples L+R INPUTS only, does not support resampling.
    • Configured on the Sample Settings Page—
      • Press RESAMP to toggle between Sample (DIM), Resample (), and Looping Recorder (MAGENTA).
      • Set SIZE of the Looping Recorder (8, 16, 24, or 32 sec).
      • Set THRSH to enable threshold based Auto-Freeze.
  • New: Dry THRU Option — Bypass BLUR.
    • Press LATCH+THRU
    • The THRU LED will turn RED when THRU is dry, GREEN when passed thru BLUR.
  • New: Lock your THRU Setting — Avoid accidental toggles.
    • Hold LATCH+THRU for .5 sec to toggle.
    • The THRU LED will turn PURPLE and lock to its current state when locked.
  • New: Grain Pitch MOD Output option.
    • Can be assigned to MOD A or B.
    • BLUE to match the quantized output colour of some of our other modules. Grain Env colour was changed to CYAN.
  • New: RESET option for NEXT Input.
    • The functionality of the NEXT input can be toggled to be a RESET input for SCAN.
    • Allows you to manually advance the SCAN position using the GATE input, and reset the position using the NEXT input.
    • RESET functionality can be enabled on the Systems Setting Page.
    • When this option is enabled, the original GATE functionality—Resetting SCAN on every GATE—is available by patching only into NEXT, leaving GATE unpatched; relying on the hardware normal to pass the gate signal from NEXT (Resetting SCAN) to GATE (Triggering the Sound).
  • New/Tweak: Random RATE Handling overhaul.
    • Much wider variation over the range of attenuation.
    • Random Grain Probability when assigning RAND negatively.
    • See new Random Section in Manual.
  • Tweak: Internal Random Source is now Unipolar for most Params
    • Allows for greater control and more variety in random modulation.
    • See new Random Section in Manual.
  • New: System Settings Page. — Only 2 Settings!
    • Long press ALT+REVERSE (~4 sec) to open.
    • Press RAND to Toggle the Internal Random Source type.
      • YELLOW = Unipolar
      • YELLOW/PURPLE (BLINKING) = Bipolar
    • Press LATCH to Toggle the RESET function for NEXT.
      • DIM = NEXT (Default)
      • AMBER = RESET
    • ALT to Exit
  • Tweak: EMPTY Sound BLUR settings are now saved in the State/Preset, and not the Global Settings.
  • Fixed: Stabilize Sync Clock with “RUN/STOP” style clocks (common with MIDI devices/daws).
  • Fixed: File Handling / Folder Position tweaks, should be more intuitive, and track changes to /RECS better.
  • Fixed: Currently Playing Sound was Stopping when clearing a Sound.
  • Fixed: Can clear a slot with a Missing WAV file.
  • Fixed: Random Rate modulation was not applied properly (was only applying a jitter to the parameter).
  • Fixed: Minor Bug Fixes and Tweaks.
